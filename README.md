## Overview

CMU EMS Bike Ops gives bike operations teams a central place to manage readiness reviews, bike-specific issue histories, jumpkit checks, pre-ride inspections, QR-based forms, and in-service decisions. Everything is presented through an interface that can be opened in a web browser.

Alongside its operational tools, the hub provides quick access to tutorials, repair contacts, maintenance instructions, and inventory information covering tools, parts, locks, keys, and orders. Because the application is distributed as one HTML file, it is also suited to use when an internet connection is unavailable.

---

## What It Includes

- View fleet readiness from a dedicated bike status dashboard.
- Maintain issue records for each individual bike.
- Run jumpkit and pre-ride safety inspections.
- Reach QR code forms for convenient reporting in the field.
- Decide whether a bike should remain in service or be taken out of service.
- Find maintenance instructions, repair contacts, and tutorial videos.
- Organize inventory for tools, parts, locks, keys, and orders.
- Reach manager-only functions through a soft passcode unlock.
- Run the single-file HTML application in offline-capable settings.

## Using the Hub

The following sequence describes a common operating routine:

1. Open the Bike Ops HTML file in a web browser.
2. Check the readiness dashboard before deployment or the start of a shift.
3. Choose a bike to view and assess its existing issues.
4. Perform the jumpkit and pre-ride safety checks.
5. Apply the decision tool to determine the bike's service status.
6. Open or submit the appropriate QR form for field reporting.
7. Refer to repair contacts, videos, and maintenance material for follow-up tasks.
8. Maintain records for tools, parts, locks, keys, and orders.
9. Open manager controls when administrative updates are needed.

4. Save updates before closing the browser tab or local file.

## Frequently Asked Questions

### What teams use CMU EMS Bike Ops?

The hub is designed for teams responsible for EMS bike readiness, inspections, issue tracking, service decisions, and associated operational materials.

### Is an installer required?

No. Download the static HTML file and open it directly in a web browser.

### Will the app work offline?

The single-file application is offline-capable. Videos and other external or linked resources can still require an internet connection.

### Where do I change settings?

Settings and manager functions are available within the HTML application. Manager-only sections are protected by a soft passcode unlock.

### How can I document a bike issue?

Add the problem to the appropriate bike record, or use one of the available QR code forms for reporting from the field.

### What if the HTML file will not open?

First verify that the download completed successfully and try opening the file in a current browser. If the problem remains, download the latest build and test that copy.

### How are new updates provided?

New builds are made available through the project's hosted build location. When an update is released, download the newest available copy.
